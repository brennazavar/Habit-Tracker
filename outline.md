# Overview

Habit tracker with different views to display metrics.

# Features

### Habits with a title and optional overview note

EX: title: Drink water, Note: 40 oz.

### Views

- Daily - sun thru saturday bubble options at top to select day, calendar option to select specific date next to this
- Weekly - square filled/unfilled boxes for each day of the week in a row, each row is a habit
- Monthly (dropdown to select habit)
- Yearly (dropdown to select specific habit)

shows daily
